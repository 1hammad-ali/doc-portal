# ARCHITECTURE DECISIONS LOG

| Date | Decision | Rationale |
| :--- | :--- | :--- |
| 2026-11-21 | **Modular Express + TypeScript Backend Architecture** | High-performance, low-latency, modular route/service/controller separation with zero decorator overhead and fast startup; native ES/TS compatibility with Node.js v24. |
| 2026-11-21 | **PostgreSQL 16 + Prisma ORM** | Relational integrity for cross-department hierarchies, junction tables (`LetterFileLink`), and full-text search capability over subjects, diary numbers, and OCR text (`ocrExtractedText`). |
| 2026-11-21 | **Many-to-Many Multi-File Linking (`LetterFileLink`)** | Government documents must physically and digitally reside in multiple files (Main Org File, Officer File, Case File, Project File) simultaneously with individual folio numbers, without copying/duplicating binary storage objects. |
| 2026-11-21 | **Two-Tier RBAC (Department & Folder ACLs)** | Real-world government officers manage multiple departments simultaneously (`UserDepartmentAccess`) and require granular read/write/checkout permissions on confidential folders (`UserFolderPermission`). |
| 2026-11-21 | **Physical Custody State Machine with Overdue Alerts** | Eliminates untracked loss of physical paper originals. Hardcopy status (`ATTACHED_IN_FILE`, `ISSUED_OUT_TO_OFFICER`, `IN_TRANSIT_DISPATCH`, `MISSING_UNTRACED`) with strict return deadlines triggering red dashboard alarms. |
| 2026-11-21 | **Sovereign Emerald (`#0B4F32`), Gold (`#C59B27`), Slate (`#111C18`) UI Theme** | Executive government aesthetic with high contrast, 3-zone layout (Floating Sidebar, Fluid Center Canvas, Right Live Timeline Rail), and split-view document drawer. |
| 2026-11-21 | **Dual Barcode Input Architecture** | Supports both high-speed USB hardware barcode scanners (global keyboard-wedge listener hook) and HTML5 camera/webcam scanners for tablet/laptop intake. |
| 2026-11-21 | **Python Microservice for OCR & Barcode Decoding** | Decouples CPU-intensive rasterization, Tesseract/Paddle OCR, and `pyzbar` barcode decoding from the primary Node.js API. |
| 2026-11-21 | **Universal Barcode Route Resolver Pattern** | Supports both `/api/v1/barcode/:code` and `/api/v1/barcode/lookup/:code` to gracefully handle hardware scanners, camera decoders, and direct URL lookups for both Letters and File Jackets. |
| 2026-11-21 | **Autonomous Native Host Database Engine** | Utilizes native PostgreSQL 18.7 running on port 5432 with persistent storage in `postgres_data`, ensuring full autonomous migrations and database seeding without requiring elevated Windows administrative UAC prompts. |
| 2026-11-21 | **In-Memory Combined PDF Dossier Engine (`pdf-lib`)** | Compiles multi-letter files on demand into an official unified PDF book with Cover Index Page, dynamic Table of Contents, and Folio Separator Banners without writing temporary files to disk. |
| 2026-11-21 | **Multi-Token Concept & Story Search Engine** | Tokenizes natural language queries (filtering English & Urdu-Roman conversational terms) and executes weighted searches across subject, summary reasons, OCR text, and file linkages with contextual snippet extraction. |
| 2026-11-21 | **Granular 7-Way Department Access Matrix** | Replaces monolithic roles with per-department operational toggles (`canView`, `canCreate`, `canEdit`, `canDownmark`, `canCheckoutPhysical`, `canExport`, `canDelete`) and file-level overrides (`UserFolderPermission`). |
| 2026-11-21 | **Physical Custody Out-Register Ledger Pattern** | Records mandatory recipient officer name, designation, auto-server timestamp (`checkedOutAt: NOW()`), and return timestamp for physical audits and dashboard alerts. |
| 2026-11-21 | **Session Lifecycle & Audit-Logged Logout Pattern** | Explicit `POST /api/v1/auth/logout` endpoint logging `USER_LOGOUT` in `AuditLog`, clearing client-side storage, and enforcing client route guards. |
| 2026-11-21 | **Certified Inline PDF Streaming & Dynamic Letterhead Synthesis** | Flexible query-token streaming (`GET /api/v1/letters/:id/stream?token=...`) with seamless fallback to `pdf-lib` generated official government letterhead and cryptographic SHA-256 seal stamp. |
| 2026-11-21 | **Cryptographic Time-Bound Sharing & Forensic Watermarking** | Random 48-char crypto tokens with bcrypt password verification, dynamic client-IP & timestamp diagonal watermark, anti-screenshot window blur listeners, and forensic `ShareAccessLog` tracking. |
| 2026-11-21 | **Official Minute Notes Sheet Pattern** | Distinct `LetterNote` entity linked to letters and officers, providing chronological government note sheet recording with confidential internal flags. |
| 2026-11-21 | **Executive Soft Glassmorphism & Eye-Comfort UI** | Translucent frosted white cards (`rgba(255,255,255,0.82)`, `backdrop-filter: blur(16px)`) over alabaster mist-sage canvas `#EEF2F0`, reducing long-hour screen glare while preserving Sovereign Emerald (`#0B4F32`) and Gold (`#C59B27`). |
